# Heart Disease Risk Analysis Using Clustering and Fuzzy Logic

## Project Overview
This project analyzes patient health data to explore patterns associated with heart disease risk. It combines clustering techniques, fuzzy logic, and genetic algorithms to develop an interpretable risk assessment system.

## Project Workflow
- Exploratory Data Analysis (EDA)
- Data Preprocessing and PCA
- K-Medoids Clustering
- Hierarchical Clustering
- Fuzzy Logic Risk Assessment
- Genetic Algorithm Optimization
- Integrated Risk Classification

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, PCA, K-Medoids, Hierarchical Clustering, Fuzzy Logic, and Genetic Algorithms.

## Risk Categories
The system classifies risk levels into:
- Low Risk
- Medium Risk
- High Risk

## Project Structure
- `notebook.ipynb`: Data analysis and implementation.
- `data/`: Dataset files.

## How to Run
1. Clone or download the repository.
2. Install the required libraries using `requirements.txt`.
3. Open the Jupyter Notebook.
4. Run the notebook cells in order.
